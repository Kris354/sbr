# СБР — Сервис бронирования ресурсов

Готовый frontend-прототип на Vue 3 + Vite + Vue Router. Интерфейс собран по предоставленному PDF-макету: приветственный экран с фотографией переговорной, нижняя навигация, каталог карточек, календарь и блок активных приглашений.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно http://localhost:5173/).

Для production-сборки:

```bash
npm run build
```

## Реализовано

- Разделы «Аппаратура», «Люди», «Пространство», «Профиль».
- Поиск по каталогу и сортировка по алфавиту.
- Добавление ресурса через форму.
- Карточки ресурсов с действиями «Пригласить» и «Подробнее».
- Переключение месяцев и выбор даты в календаре.
- Создание, принятие и отклонение приглашений.
- Проверка простого конфликта подтверждённого бронирования одного ресурса на один временной интервал.
- Регистрация, вход и редактирование демонстрационного профиля.
- Сохранение ресурсов, приглашений и профиля в localStorage.

## Важно

Это frontend-демонстрация. Реальные уведомления другим сотрудникам, синхронизация с внешними календарями, авторизация и общая база данных требуют backend/API и здесь не реализованы. Фотографии загружаются по внешним URL, поэтому для их отображения нужен интернет.
